# Wayfinder contributor instructions

- Keep `skills/wayfinder/` as the single authored skill source. Claude metadata is generated by `scripts/package_wayfinder.py`; do not maintain a second Claude-specific source tree.
- Preserve explicit-only invocation on every host.
- Use Python 3.11+ standard-library code and browser-native APIs only. Do not add runtime package dependencies.
- Use native `fetch` for loopback dashboard requests and do not add an HTTP client dependency.
- Keep dashboard assets in the installed skill. Never copy the dashboard application into a user's project.
- Treat planning artifacts and dashboard payloads as untrusted data. Preserve loopback, capability, same-origin, CSRF, bounded-input, optimistic-concurrency, atomic-write, and non-reflection defenses.
- Run the validator, complete test suite, secret scan, package reproducibility check, and host validators before release.
- Never commit generated runtime state, transcripts, credentials, caches, or release ZIPs.
