# Changelog

All notable changes to Wayfinder are documented here. The project follows [Semantic Versioning](https://semver.org/).

## [0.2.0] - 2026-08-23

### Added

- Explicit-only conversational intake for ChatGPT desktop, Codex, and Claude Code.
- Domain-aware routes for software, general/construction, finance/reporting, other, and hybrid projects.
- Plain-language route and named-technology comparisons with grounded recommendations and user-proposed alternatives.
- Durable revisioned decisions, evidence, assumptions, invariants, gates, checkpoints, receipts, and implementation baselines.
- Append-only revalidation for previously unknown facts and targeted reopening after material change or failed/stale delivery gates.
- Dependency-free seven-section local dashboard with deep links, search, filters, responsive navigation, keyboard support, and narrow interactive decision recording.
- Deterministic OpenAI skill, Claude skill, OpenAI plugin, and Claude plugin packages from one canonical source.
- Python 3.11+ pre-mutation checks, hostile-input hardening, secret-safe packaging, and exact archive verification.

### Security

- Loopback-only serving, per-launch capabilities, same-origin and CSRF enforcement, optimistic concurrency, bounded schemas, atomic persistence, and non-reflective diagnostics.
- Package rejection for private state, secret-like content, keys, symlinks, ambiguous binaries, unsafe archive paths, duplicate JSON keys, and non-deterministic metadata.
